Enterprise Travel & Expense Management System

A full-stack application that helps enterprises streamline travel and expense tracking, with multi-level approvals, role-based access control, real-time notifications, and secure authentication.

Overview

Companies often track business travel and expenses through scattered emails and spreadsheets. This system centralises the process: employees submit requests and expenses, managers review them through approval levels, and everyone is notified in real time.

Key features

  • Multi-level approval workflow for travel and expense requests.
  • Role-based access control so each user sees only what their role allows.
  • Real-time notifications using Socket.IO.
  • Secure authentication with JWT and Bcrypt password hashing.
  • Receipt and file uploads through Cloudinary.
  • Email notifications with Nodemailer.
