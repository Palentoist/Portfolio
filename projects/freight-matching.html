Smart Freight Matching & Recommendation System

An academic project that matches shipments with suitable vehicles by filtering out unsuitable options and ranking the rest with a weighted scoring model.

Overview

Choosing the right vehicle for a shipment affects cost, efficiency, and cargo safety. This system automates that decision: it first removes vehicles that physically cannot carry the shipment, then ranks the remaining options so the best match appears first.

How it works

  1. Filter: vehicles that are physically unsuitable for the shipment are removed.
  2. Score: the remaining vehicles are ranked using weighted factors: capacity utilisation, cost, availability, route distance, cargo suitability, and fuel efficiency.
  3. Estimate: machine learning supports cargo volume and damage estimation.

Key features

  • Two-stage matching: hard constraints first, then weighted ranking.
  • Multi-factor recommendation scoring.
  • Route distance calculations through a Maps API.
  • Redis for fast access to frequently used data.
