Mafia Game

A browser-based multiplayer Mafia game with a React frontend and a Node.js backend, using real-time communication so players can interact live.

Overview

Mafia is a social deduction game where hidden roles, discussion, and voting decide the winner. This project brings that experience to the browser so friends can play together in real time without installing anything.

Key features

  • Lobby & room system, players create or join a room with a short code; the host starts the game once enough players are present.
  • React single-page frontend built with Vite for fast development and loading.
  • Node.js and Express backend that manages game logic and connected players.
  • Real-time chat and voting, Socket.IO events broadcast messages and vote counts instantly to every player.

Tech stack

Challenges and solutions

Keeping every player's view of the game in sync was the hardest part. I made the server the single source of truth for game state and only sent each client the information it was allowed to see, so hidden roles stayed hidden. Handling disconnects was the other challenge. I added a reconnection window and had the server mark players as inactive so a dropped connection didn't stall voting.

What I learned

This project taught me how real-time apps differ from request/response apps, you have to design socket events as a small protocol and think about ordering, retries, and what happens when a client misses a message. It also gave me practice structuring a full-stack app cleanly: game logic on the server, a thin React client that just renders state and emits events
