Overview

Mafia is a social deduction game where hidden roles, discussion, and voting decide the winner. This project brings that experience to the browser so friends can play together in real time without installing anything.

Key features

  • Real-time multiplayer communication powered by Socket.IO.
  • React single-page frontend built with Vite for fast development and loading.
  • Node.js and Express backend that manages game logic and connected players.
