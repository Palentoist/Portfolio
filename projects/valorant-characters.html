Overview

This project lets visitors browse Valorant agents and learn about their abilities. It focuses on consuming data from a public API and presenting it in a clear, game-inspired interface.

Key features

  • Character data fetched from the Valorant API with JavaScript.
  • Details about each character and their abilities.
  • Responsive, themed layout built with HTML and CSS.
  • Deployed on Vercel.
