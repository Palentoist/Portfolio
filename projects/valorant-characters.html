Valorant Characters

A Valorant-themed web experience featuring a collection of characters, their abilities, and other game-related information pulled from an API.

Overview

This project lets visitors browse Valorant agents and learn about their abilities. It focuses on consuming data from a public API and presenting it in a clear, game-inspired interface.

Key features

  • Character data fetched from the Valorant API with JavaScript.
  • Details about each character and their abilities.
  • Responsive, themed layout built with HTML and CSS.
  • Deployed on Vercel.
  • Search agents by name.
  • Filter agents by role (Duelist, Controller, Sentinel, Initiator).
  • Loading and error states while the API data is fetched.
  • Smooth animations and hover effects on agent cards.

Tech stack

  • HTML
  • CSS
  • JavaScript
  • Valorant API
  • Vercel

Screenshots

Challenges and solutions

The main challenge was handling asynchronous API data, some agents had missing or differently formatted fields, which required defensive checks before rendering. I also had to manage loading and error states so the page never appeared broken while data was being fetched. Finally, making the grid layout responsive on small screens required careful use of flexbox/grid and media queries.

What I learned

I learned how to fetch data from a public API with fetch/async-await, parse JSON, and render it dynamically into the DOM. I also gained experience handling loading and error states and structuring code so the UI updates cleanly. Deploying to Vercel taught me how to configure a project for production hosting and how to debug build/runtime issues.
