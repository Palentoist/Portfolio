Overview

This web application lets users work with real-estate listings through a Laravel backend. It was built to practise server-side development, database-driven pages, and deploying a PHP application to the web.

Key features

  • Laravel and PHP backend with a MySQL database.
  • Passwords protected with Bcrypt hashing.
  • Protection against cross-site scripting (XSS).
  • Responsive pages using Bootstrap, with Vanilla JS and jQuery for interactivity.
  • User registration and login with session-based authentication.
  • Browse, view, and manage property listings.
  • Search and filter listings by location, price, and property type.
  • Admin panel for creating, editing, and deleting listings.

Tech stack

Challenges and solutions

The main challenge was deploying a Laravel application with its Vite-built assets to shared hosting, which required configuring the public directory as the web root and handling environment variables securely. I also had to design the database schema with proper relationships between users and listings, and secure all user input using Laravel's validation and Blade's automatic escaping to prevent XSS. Debugging migration-related issues and keeping the local and production databases in sync taught me to plan schema changes carefully.

What I learned

I learned how the MVC pattern separates application logic from presentation, and how Laravel's routing, controllers, models, and Blade templates work together to build maintainable features. I also gained a solid grounding in web security basics, password hashing with Bcrypt, CSRF protection, input validation, and XSS prevention. Finally, deploying the finished application taught me how to configure a production environment, manage dependencies with Composer, and build assets with Vite.
